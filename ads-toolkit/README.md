# Рекламная студия

Одна статическая страница с двумя вкладками.

- **Креативы**: бриф (продукт, аудитория, оффер, площадка, формат, тон, призыв) превращается в готовые промпты для Moda, Higgsfield, vidIQ и текстов.
- **Аналитика**: калькулятор CTR, CPC, CPM, CVR, CPA, ROAS, ROI и точки безубыточности, плюс конструктор запроса к Supermetrics.

Запуск: открыть `index.html` в браузере. Данные из рекламных кабинетов страница сама не загружает: промпт копируется в чат, где подключён Supermetrics.

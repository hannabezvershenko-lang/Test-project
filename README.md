# Лучшая шаурма Людвигсбурга

Одностраничный промо-сайт шаурмичной: тёмная тема, тонкий гротеск, 3D-рендер шаурмы в центре.
При наведении шаурма раскрывается: проигрывается последовательность из 24 кадров.

## Запуск

Статический сайт, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

| Путь | Что это |
|---|---|
| `index.html` | разметка |
| `styles.css` | стили, адаптив, анимации |
| `main.js` | раскрытие шаурмы (кадры на canvas), курсор, параллакс, искры, магнитные кнопки, 3D-наклон карточек, reveal при скролле |
| `assets/frames/f00–f23.webp` | кадры раскрытия (PNG с прозрачностью → WebP) |
| `assets/img/` | крупные планы и вырезки для карточек |
| `assets/fonts/` | Inter Display (OFL), подмножество латиница + кириллица |

## Шрифт

В CSS сначала подключается **Neue Haas Grotesk Display**, если он установлен у посетителя (`local()`).
Это коммерческий шрифт, поэтому в репозитории его нет. Если у вас есть веб-лицензия, положите файлы
`.woff2` в `assets/fonts/` и замените `url(...)` в блоке `@font-face` в начале `styles.css`.
Иначе используется близкий по характеру Inter Display Thin/ExtraLight.

## Замена изображений

Кадры отрендерены процедурно в Blender. Их можно заменить своими фото или видео из Higgsfield:
нужны 24 кадра `f00.webp … f23.webp` одного ракурса, формат 4:5 (960×1200), прозрачный или тёмный фон.
`f00` — закрытая шаурма, `f23` — полностью раскрытая.

## Что заменить перед запуском

Адрес, телефон, часы работы и цены в `index.html` — заглушки.

# Noctis Motors — сайт продажу преміальних авто в Україні (`auto/`)

Окремий статичний сайт у папці `auto/` (шрифти беруться із загальної `assets/fonts`).
Відкрити: `http://localhost:8000/auto/`. Одним файлом: `noctis-motors.html` (збирається `python3 auto/build.py`).

| Шлях | Що це |
|---|---|
| `auto/index.html` | розмітка; авто в hero — inline SVG (вигляд спереду) з відображенням на підлозі |
| `auto/styles.css` | стилі, контровий світ, перспективна підлога, анімації дверей і фар, адаптив |
| `auto/main.js` | дим на canvas, відчинення дверей і блимання фар при наведенні (на сенсорних екранах — за дотиком), параллакс, лічильники, фільтр моделей, конфігуратор з розрахунком ціни в USD, форма з маскою +38 |
| `auto/build.py` | збирає `noctis-motors.html` з усім вбудованим (шрифти, фото) |

## Фото авто в каталозі

Покладіть фото в `auto/assets/cars/` з такими іменами (горизонтальні, бажано 1200×675 або більше, темне тло):

| Файл | Модель |
|---|---|
| `porsche-911-turbo-s.jpg` | Porsche 911 Turbo S |
| `ferrari-296-gtb.jpg` | Ferrari 296 GTB |
| `mercedes-maybach-s680.jpg` | Mercedes-Maybach S 680 |
| `range-rover-sv.jpg` | Range Rover SV |
| `lamborghini-urus-se.jpg` | Lamborghini Urus SE |
| `porsche-taycan-turbo-s.jpg` | Porsche Taycan Turbo S |

Поки фото немає, картка показує стилізований силует — сайт не ламається. Після додавання фото
перезберіть одиночний файл: `python3 auto/build.py`.
Використовуйте лише фото, на які у вас є права (власні, від дилера, з фотобанку з ліцензією або
Wikimedia Commons із зазначенням автора та ліцензії).

Ціни орієнтовні, телефон, адреса та назви партнерів — заглушки.

# Palomar — landing page

Fixed navbar + full-viewport video hero. React + TypeScript + Vite + Tailwind CSS.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/ (relative paths, can be served from any folder)
```

All markup is in `src/App.tsx` (`Navbar`, `Hero`, `TrustedBy`); animations and globals are in `src/index.css`;
brand colors and fonts are in `tailwind.config.js`.

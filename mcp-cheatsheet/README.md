# Шпаргалка по MCP-коннекторам

Одна статическая страница: 9 коннекторов (Spline, Higgsfield, Wonder, Moda, vidIQ, Supermetrics, Figma, Canva, TinyFish) и по 3 готовых промпта к каждому.

Запуск: открыть `index.html` в браузере. Сборка не нужна.

Чтобы добавить коннектор или промпт, отредактируй массив `DATA` в конце `index.html`.
